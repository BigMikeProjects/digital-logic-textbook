Step 1 of 3 — draw the FSMD — a state diagram with register transfers beside the states and data conditions on the arcs
What an FSMD adds to a state diagram
  • Register transfers beside each state: what the data does while the machine sits there.
  • Arcs that read the data. A plain FSM leaves a state on an input; this one leaves on C = 6, a fact about a register.
  • It is the whole algorithm in one picture, and not yet hardware. Steps 2 and 3 split it.
Why C = 6, not 7
The transfer and the transition happen on the same clock edge. Leaving UP at C = 6 still performs C ← C + 1, so C arrives in DOWN as 7. Detecting one count early lets the count reach the end before it turns.
Checked in simulation: conditions at 7 and 0 instead wrap 7 → 0, then toggle 0, 7, 0, 7 forever.
Step 2 of 3 — build the datapath — read the FSMD three times
Registers → a register
The FSMD names one register, C. The datapath gets one 3-bit register, clocked. Its value feeds the arithmetic and leaves as the count.
Register transfers → arithmetic + a mux
Each different right-hand side is a block: C + 1 and C − 1. Two sources for one register need a mux. Its select is a new control input, up: 1 picks C + 1, 0 picks C − 1.
Data conditions → comparators
Each condition on an arc is a comparator: C = 6 and C = 1. Their outputs are new status outputs, at6 and at1, for whoever operates the datapath.
The datapath does not know which way it is counting. It offers both results and reports where C is. Something must drive up: that is step 3.
The datapath — ports: control in, status out, the count out
Step 3 of 3 — derive the controller — from the same FSMD
States carry over
UP and DOWN, reset into UP: exactly the FSMD's states.
Register transfers → control outputs
C ← C + 1 in UP becomes up = 1 inside UP; C ← C − 1 becomes up = 0 inside DOWN. Moore: the output lives in the state.
Data conditions → status inputs
C = 6 becomes the input at6; C = 1 becomes at1. Same arcs, now labelled with wires from the datapath.
Stay otherwise → self-loops, equations
Self-loops at6′ and at1′ complete it. S = 1 means UP: S+ = S·at6′ + S′·at1, up = S.
Nothing new in this box: an ordinary Moore FSM. Only where its inputs come from is new.
In practice you write the RTL and the tools build both boxes. The three steps are how to read what you wrote.
The controller — a traditional FSM whose inputs are the datapath's status and whose output is its control

The controller, as equations
S = 1 means UP   ·   up = S
S+ = S·at6′ + S′·at1
In UP only at6 matters; in DOWN only at1. The other status is ignored (cycles 1 and 8 in the table).
Why 6 and 1, not 7 and 0
Moore output: up changes one clock after the state. So the datapath must flag the turn one count early: at 6 the machine still adds once more and reaches 7; at 1 it still subtracts once and reaches 0.
Checked in simulation: comparing at 7 and 0 instead wraps 7 → 0, then toggles 0, 7, 0, 7 forever.

Definitions
D or Esc closes
FSMD
Finite state machine with datapath. A state diagram with register transfers beside the states and data-dependent conditions on the arcs: the whole algorithm in one picture. Introduced in Introduction to Register Transfer Level Design.
Register transfer
C ← C + 1: on the clock edge, register C loads the value C + 1. Written beside the state that performs it.
Data condition
An arc condition that reads a register, such as C = 6, rather than an external input. It becomes a comparator in the datapath and a status wire to the controller.
Datapath
The registers, arithmetic, multiplexers and comparators, built in step 2. It holds C and can add or subtract 1, but does not decide which.
Controller
An ordinary FSM, derived in step 3, that operates the datapath. Its state bits hold what the data does not: here, the direction.
Control signal
Controller → datapath. Here up is the mux select: 1 = C + 1, 0 = C − 1.
Status signal
Datapath → controller. Here at6 is 1 when C = 6 and at1 is 1 when C = 1.
Moore output
Written inside the state, not on the arcs, so it changes one clock after the state changes. See Mealy versus Moore.
