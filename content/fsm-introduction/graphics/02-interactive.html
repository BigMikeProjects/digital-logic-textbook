One Machine, Three Pictures
The three boxesevery synchronous FSM, no exceptions · click a box, or press N / S / O
Only one box remembers. The state register holds the state. The other two boxes are ordinary combinational logic, wired in a loop.
What each box doesclick one, or press its key
next-state logic N
Combinational. Reads the inputs and the current state; produces D, the state to load at the next edge.
state register S
D flip-flops on one clock — the only memory. Changes only on the rising edge. RESET loads state 0.
output logic O
Combinational, from the state alone: MAX = Q1·Q0. Outputs that read only the state make a Moore machine.

As a state diagrambubbles = register values · arcs = what the next-state logic does · the label inside = the output
The machine: a 2-bit up/down counter. U=1 counts up, U=0 counts down, wrapping both ways. MAX is 1 in state 3 only.

As a state tablethe same eight arcs, one per row · U and the current state in, the next state and the output out
Read a row: with input U and state Q1Q0, the next edge loads Q1⁺Q0⁺. Eight rows — one per arc on beat 2.
MAX is a column of the state
MAX never changes within a state — the output reads only the state: a Moore machine.
