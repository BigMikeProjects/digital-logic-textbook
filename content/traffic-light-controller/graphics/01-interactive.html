One module, read off the FSMD: register TR with its adder and mux, one comparator with a mux on its limit D (the same pattern as Timer Circuit), and four one-hot flip-flops written one term per arc.

                

                

                    

                        
How long each phase lasts — iverilog, DG = 4, DY = 2

                        

                    

                    

                        
Why the mux on TR is picked by tc

                        
The FSMD sets TR ← 0 on every arc that leaves a phase, and those arcs are taken exactly when tc = 1. So tc picks the 0 input, and every phase starts counting at TR = 0.

                    

                    

                        
Never both green

                        
NS_G = QNSG and EW_G = QEWG. One-hot means exactly one flip-flop is 1, so the two greens can never be 1 together.

                        
DG = 4 and DY = 2 keep the trace short. A real light uses the same circuit with a wider TR, or counts once per second instead of once per clock.

Definitions
D or Esc closes

            

                
Phase
One setting of the six lights. This controller has four, always in the same order: NS green, NS yellow, EW green, EW yellow. Each phase is one state.

                
NSG, NSY, EWG, EWY
The four states, named for the road that may move and its light: NS is the North–South road, EW the East–West road, G green, Y yellow. Reset starts in NSG.

                
The six lights
NS_R, NS_Y, NS_G and EW_R, EW_Y, EW_G: red, yellow and green for each road. All Moore outputs: each depends only on the state.

                
TR
The register that counts clocks in the current phase: TR ← TR + 1 while the phase goes on, TR ← 0 on the clock it ends. The same register, adder, mux and comparator pattern as Timer Circuit.

                
DG, DY
How many clocks a green or a yellow phase lasts: 4 and 2 here so the trace fits on the screen. A green phase ends when TR = DG − 1, a yellow one when TR = DY − 1.

                
green
Control signal, controller → datapath: 1 in NSG and EWG. It picks DG at the mux on the comparator’s limit; 0 picks DY.

                
tc
Status signal, datapath → controller: the comparator’s output, 1 when TR equals the current state’s limit (DG − 1 in NSG and EWG, DY − 1 in NSY and EWY). On tc the controller moves to the next phase.

                
Mealy control signal inside a datapath
A control signal that depends on a status input, like clr = tc here. Safe inside the datapath, because the register only samples it at the clock edge; outputs that leave the circuit stay Moore.

                
One-hot
One flip-flop per state, exactly one of them 1. The next-state logic is one term per arc into each state. See FSMD - Finite State Machines with Datapaths.
