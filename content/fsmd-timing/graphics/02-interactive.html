Definitions
D or Esc closes
FSMD
Finite state machine with datapath. A state diagram with register transfers beside the states and, when the data decides, conditions that read a register. Introduced in Introduction to Register Transfer Level Design; the three-step method is FSMD - Finite State Machines with Datapaths.
Register transfer
R ← X: on the clock edge, register R loads X. Written beside the state that performs it, and performed on the edge that leaves that state.
Datapath
The registers, arithmetic, multiplexers and comparators, built in step 2. Here one register and one mux: it can load 0, X or Y, but does not decide which.
Controller
An ordinary FSM, derived in step 3, that operates the datapath. Its state is the only memory of what a has done.
Control signal
Controller → datapath. Here selX and selY pick the mux leg; neither asserted means the constant 0.
Status signal
Datapath → controller: a fact about a register, such as a comparator output. This machine has none; every decision reads the input a.
One-hot
One flip-flop per state, exactly one of them 1. Each next-state equation is read off the diagram: one term per arc into the state, the source flip-flop AND the arc’s condition.
Moore output
Written inside the state, so it changes right after the edge that changes the state, never in the middle of a cycle. See Mealy versus Moore.
Sampling at the edge
A register captures the value present on its input just before the rising edge. X and Y may change any time; only their values at an edge whose state loads them ever reach R.
R at cycle 0
R has no reset of its own, so it is unknown (??) until A’s R ← 0 lands at the first edge. That is what A’s transfer is for.
