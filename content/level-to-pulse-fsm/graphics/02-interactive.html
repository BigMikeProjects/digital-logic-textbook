Input L is a level — it goes high and stays high. We want P to fire exactly one clock wide on each rising edge of L, no matter how long L stays high.
PULSE is a pass-through state: you can only sit in it for one clock (L=1 sends you on to HIGH), so P is high for exactly one clock. Getting another pulse requires returning to LOW first — a new edge.
Moore machine — output depends on state only → glitch-free, exactly one clock wide

From the K-mapsThe three expressions come straight from the state table's K-maps, using the 11 don't-cares to simplify. Verified: they reproduce the table exactly, and the unused state 11 recovers to a legal state within a couple of clocks (self-starting).
Moore vs. MealyThis registered Moore design emits the pulse the clock after the edge, guaranteeing a clean full-clock-wide P. A Mealy version needs one fewer state and can fire the same cycle — but risks a glitch pulse — a sliver narrower than a full clock — if L is noisy. We use Moore for the clean pulse.
Each output gets its own K-map over Q1 Q0 L. Columns are in Gray order (00 01 11 10) so neighboring cells differ in one variable — that is what makes a rectangle a valid group. d = don't-care from the unused state 11.
