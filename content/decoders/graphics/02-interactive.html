A decoder turns a binary code into a one-hot line — n inputs drive 2n outputs, and exactly one of them is asserted.

Output Yᵢ is minterm mᵢ. A decoder generates every minterm of its inputs — which is why you can build any function out of one.

2-to-4 decoder — case
module dec2to4 (input [1:0] a, input en, output reg [3:0] y); always @* begin y = 4'b0000; // default first — see the warning below if (en) case (a) 2'b00: y = 4'b0001; 2'b01: y = 4'b0010; 2'b10: y = 4'b0100; 2'b11: y = 4'b1000; endcase end endmodule
⚠
Drop that y = 4'b0000; default and the en = 0 path assigns nothing — so y must hold its old value, and the synthesiser infers a latch. Combinational logic that accidentally remembers is the classic Verilog bug; assign a default before every conditional.
