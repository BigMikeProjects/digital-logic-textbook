One literal, two variables: the unsigned reg and the signed reg hold the same bits. Only the reading differs.
Too many digits → silently truncated
8'h1A5 needs 9 bits; only the low 8 are kept, so it stores a5. The compiler only warns. Try size 8, hex, 1A5.
No size → 32 bits
'hA5 or plain 165 is a 32-bit constant. Fine in a testbench; in a design it can widen an expression when you didn’t mean it to. Try size none.
A minus sign negates the bits
-8'd91 means “negate the 8-bit pattern for 91” → 10100101. The unsigned reg reads that as 165; only the signed reg says -91. Try size 8, decimal, −91.
