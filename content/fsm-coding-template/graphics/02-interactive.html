The state diagram — from Level-to-Pulse FSM
L is a level; P is one clock wide for each rising edge of L. Moore: P lives inside the bubbles. The encoding LOW = 00, PULSE = 01, HIGH = 10 leaves 11 unused.

level_to_pulse_2blk.v — the two-block variant
Same hardware, one fewer block: next-state and output logic share one always @(*) (shaded). The defaults at its top give next and P a value on every path, so no latch. Both forms are fine; teach three blocks first, because each block is one drawing.
1= in the state register
else state = next; // ✗
With one register it happens to work. Once another clocked block reads state on the same edge, which value it sees depends on which block the simulator runs first. Use <=, as in Blocking versus NonBlocking.
2A missing arm or default → a latch
case (state) LOW: … PULSE: … HIGH: … endcase
State 11 has no arm, so next keeps its old value there: memory without a clock. The synthesizer builds a latch. Cover every case, or assign a default first.
3A Mealy output
P = (state == LOW) & L;
L on the right of block 3’s = makes P a Mealy output: the pulse comes one clock earlier (P = 001000001000). An alternative, not the default: Mealy versus Moore.
4A registered output
P <= …; // moved into block 1
Move an output’s line into block 1 with <= and it comes straight off a flip-flop, glitch-free: Registered Outputs.
Register with <=, gates with =, and the file is the schematic.
DefinitionsEsc or D to close
state registerthe flip-flops that hold the state; here two D flip-flops, Q1 and Q0. Block 1. next-state logicgates that compute the D inputs from the input L and the state bits. Block 2. output logicgates that compute the output P. In a Moore machine they read only the state bits. Block 3. always @(posedge clk)runs only on the rising clock edge, so what it assigns becomes flip-flops. always @(*)runs whenever anything it reads changes, with no clock, so what it assigns becomes gates. <=non-blocking assignment: every line reads the values from before the edge; use it in the clocked block. =blocking assignment: each line sees the line above; use it in the @(*) blocks. localparama name for a constant. LOW = 2'b00 is the state assignment written down; it builds nothing. case … defaultone arm per state; default catches every pattern not listed (here the unused 11). inferred latchmemory the synthesizer adds when a @(*) block leaves a variable unassigned on some path.
