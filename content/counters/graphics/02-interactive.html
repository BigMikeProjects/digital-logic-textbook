Eight states in a ring — state = the binary count Q2 Q1 Q0. Each clock, UP=1 steps to the next count (7 → 0 closes the ring); UP=0 holds (self-loop).
Because the state assignment is just the count, there's no encoding puzzle — all the design work is in the next-state logic (Stages 2–4).

D flip-flops: next state Q⁺ is what we drive onto D2 D1 D0. UP=0 rows all hold (Q⁺ = Q); UP=1 rows add one and wrap.
Rows = UP,Q2 (Gray) · columns = Q1,Q0 (Gray). Each colored loop is a prime-implicant group; the matching-colored product term sits below the map, and they sum to the flip-flop equation. Notice the maps shrink down the bits — D0 ignores Q1 and Q2, D1 ignores Q2 — each higher bit toggles only once all the lower bits are 1.
D0 = UP ⊕ Q0|D1 = Q1 ⊕ (UP·Q0)|D2 = Q2 ⊕ (UP·Q1·Q0)
Three D flip-flops on a common clock; each bit's D is an XOR toggle enabled by the AND carry-chain UP · UP·Q0 · UP·Q1·Q0. The fed-back outputs Q0,Q1,Q2 are shown as labeled taps.

Hint: on the right, find the rows where Q2 flips. What are all the bits below it doing? A bit flips on the next count only when every bit below it is 1 — exactly when adding 1 carries into it. So bit n toggles on UP AND every lower bit, and each enable is the previous one times one more Q: the AND chain grows by one input per bit, the same carry idea as an adder. An n-bit counter needs no new K-maps.
