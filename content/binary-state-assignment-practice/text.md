## Practice Homework

This page works differently from the other topics in the Infobook. It is not a reading. It is homework: a set of practice problems to work on your own after you have studied Binary State Assignment. There is no new material here. Each problem asks you to carry the method all the way through, and the panel above checks you one step at a time rather than doing the work for you.

Work the problems in order with paper and pencil. Try every step yourself before you open its hint, and open a step's worked solution only once you have an answer of your own to compare it with. Problem 1 is a warm-up and Problem 5 is the hardest.

## About the Set

This practice set works the binary state assignment method from start to finish on five state machines. Each problem gives you the state diagram and the binary code for every state, so the only work left is the part that takes practice: building the coded state table, filling in the K-maps, and finding the minimal next-state and output equations. Because the codes are given and each answer is the only minimal one, your equations should match the answer term for term.

The method itself is developed in Binary State Assignment. Page 0 of the set reviews it in five steps, numbered 0 to 4, along with the conventions every problem uses: D flip-flops, a free complement from each flip-flop's $\bar{Q}$ pin, and unused codes treated as don't-cares.

## The Five Problems

Each problem adds one new thing to handle.

| Problem | Machine | What it adds |
|:-:|---|---|
| 1 | Up/down counter | Warm-up: four states, every code used |
| 2 | Two 1s in a row | An unused code, and the don't-cares it creates |
| 3 | 0 1 1 detector | A Mealy output, which depends on the input as well as the state |
| 4 | 1 0 0 1 detector | Five states, three flip-flops and four-variable K-maps |
| 5 | Two-request arbiter | Two inputs and two outputs |

## Working a Problem

Each problem page has five step cards, numbered 0 to 4 to match the method on page 0: understand the problem, count the flip-flops, build the coded state table, fill in the K-maps, and write the minimal equations. Every card starts empty. Work each step on paper first, then use the card's buttons:

- **Hint** gives a nudge for that step without filling anything in.
- **Show** reveals the worked step, so you can compare it with yours.

**Next hint** walks through every hint and step in order, one press at a time, and **Final answer** shows all five steps at once.

The panel is easiest to use at full size. Use the **Open full screen** button below it.
