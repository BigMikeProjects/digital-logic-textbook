What it costs — the Mealy head start is given back
Glitches after the edge — even with synchronized inputs
x and Q change on the same edge, not at the same instant. Z is 0 before and 0 after, but if x arrives first, Z can be 1 for a sliver. Moore output logic has the same hazard. Flip-flops on this clock never see it; an output pin, another clock domain or a reset input can.
A registered output is glitch-free by construction.
What it is — treat (Q, P) as the state
The two flip-flops hold LOW = 00, PULSE = 11, HIGH = 10, and 01 never happens. Every arc matches. A Moore machine whose output needs no logic: the same machine with a smarter state assignment, found by starting from the Mealy design.
Any output logic can glitch — Moore or Mealy
A Moore output Z = Q1·Q0 decodes state 11, which this machine never enters. On one edge the state goes 01 → 10: Q1 rises and Q0 falls, not at the same instant. If Q1 gets there first, the gate sees 11 for a sliver and Z pulses.
Your own flip-flops never see it: they sample only at your edges, and the sliver is gone by then. Another clock’s edges can fall anywhere.
A Mealy output has the same problem, and more (beat 3).
The fix: register it, then synchronize it
Moore or Mealy: any output that leaves its clock domain comes straight off a flip-flop. Their side still synchronizes it; the two fixes solve different problems and are used together.
FixSolvesWhere
synchronizeran input from outside the clock domainon the input
registered outputglitches on an outputon the output
Register it before it leaves, synchronize it when it arrives.
  • Register on your side. Their edges fall anywhere relative to yours, so one can land on a glitch and capture a pulse that never existed.
  • Synchronize on their side. A clean registered output still changes just after your edge, so to them it is an asynchronous input.
  • Neither alone is enough. A synchronizer can pass a glitch through as a valid pulse; a registered output alone can leave their flip-flop hovering.
Single-bit signals only: a multi-bit value needs more than one synchronizer per bit. See Synchronizers.
