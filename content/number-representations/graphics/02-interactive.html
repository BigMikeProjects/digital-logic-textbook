Number Representations — representation is a contract

The same bits — 0100 0001 — can be the number 65, the character 'A', or the hex byte 0x41. The hardware doesn’t know which; the design contract does.
Bits carry no meaning by themselves. Engineers assign meaning by choosing a representation — and this section of the Infobook is about learning the contracts you’ll choose between.
Width is a purchase:
4 bits
16 patterns · 0–15
8 bits
256 · 0–255
16 bits
65,536 · 0–65,535
every extra bit buys range and costs storage, wires, circuit area, and power
What range is required?
sets the minimum width
Can values be negative?
decides signed vs unsigned
What happens on overflow?
wrap, saturate, or flag an error
Who reads the value?
binary, decimal, hex, or symbols on the display
What does the other side assume?
interfaces must agree on width, signedness, encoding
Many real digital-logic bugs are representation bugs — the value was stored perfectly and read wrongly.
