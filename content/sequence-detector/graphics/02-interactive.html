The One-Hot Circuit
The machine watches x, one bit per clock, and raises Z for one clock each time the last four bits were 1 0 1 0. Z is a Moore output, so it belongs to a state: the clock edge that samples the fourth bit moves the machine into its “seen 1 0 1 0” state, and Z is 1 during the next clock, one column after the fourth bit.
One stream, two ways to countdigits correct = how much of 1 0 1 0 the machine holds coming into that clock · 4 correct is the state where Z is 1

One-hot: one flip-flop per state, exactly one of the five holding a 1. Each D input is one AND term per arc into that state, ORed. One Hot State Assignment explains reading the equations off the arcs and what reset has to do. No reset logic is drawn here: reset must load S0 = 1 and the other four 0, since all zeros is not a state.
