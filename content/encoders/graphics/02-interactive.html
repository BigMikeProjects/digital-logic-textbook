Interrupt arbitration
Several devices raise a request at once. The priority encoder reports the number of the most important one, and V says whether there is any request at all. This is why priority exists.
Keypad scanning
A pressed key pulls one line; the encoder turns it into a code. Two keys at once is not hypothetical here — it is the multiple-input problem, every day.
Leading-one detection
A priority encoder finds the position of the most significant 1 in a word — the core of floating-point normalisation and count-leading-zeros.

The round trip
Feed a decoder's one-hot output straight into an encoder and the original code comes back out. Same wires, opposite direction.
decoder → encoder
Press C to step the code. The one-hot line in the middle is the decoder's whole output and the encoder's whole input.
This block's Verilog idiom: casez — don't-care patterns, tested in order
The priority encoder — casez, and the branch order is the priority
module enc4to2_pri (input [3:0] i, output reg [1:0] a, output reg v); always @(*) begin a = 2'b00; v = 1'b0; // defaults first casez (i) 4'b1???: begin a = 2'd3; v = 1'b1; end 4'b01??: begin a = 2'd2; v = 1'b1; end 4'b001?: begin a = 2'd1; v = 1'b1; end 4'b0001: begin a = 2'd0; v = 1'b1; end endcase end endmodule
The plain encoder — three OR gates, and that is all
module enc4to2 (input [3:0] i, output [1:0] a, output v); assign a[1] = i[3] | i[2]; assign a[0] = i[3] | i[1]; assign v = i[3] | i[2] | i[1] | i[0]; endmodule
Note i[0] appears in neither code equation — index 0 is 00, so it contributes nothing but its presence in V.
!
The a = 2'b00; v = 1'b0; defaults are what stop the all-zeros case from inferring a latch — the same bug as the decoder, and the most common Verilog error in this course.
!
? is a don't-care only in casez. Write the same patterns under plain case and they match literally — the design silently stops working.
!
Branch order carries the priority. Reorder those four lines and the priority reverses. Unlike a truth-table case, this code is order-dependent by design.
